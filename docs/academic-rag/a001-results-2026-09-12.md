## Interpretation

A001 behaved as a highly conservative screening system.

The strongest result is recall. No ground-truth paper classified as RELEVANT or HIGHLY_RELEVANT was missed, and class-3 recall was also perfect. This is desirable for literature screening because false negatives are more costly than false positives when the objective is to avoid losing important prior work.

The binary relevant/non-relevant behavior is substantially better than the fine-grained four-class agreement. Exact 0-3 classification accuracy is only 0.417, MAE is 0.708, and quadratic weighted kappa is 0.281. Therefore, the model is useful as a broad relevance-preserving filter, but its distinction among TANGENTIAL, RELEVANT, and HIGHLY_RELEVANT is not yet strong enough to treat the ordinal score as a high-confidence ranking signal.

The current active-reading policy is the clearest weakness. Relevant retention is 1.000, but reading reduction is 0.000. In practice, the model recommended active reading for the full corpus, so it did not reduce human workload.

## Methodological conclusion

Relevance prediction and reading policy should be decoupled.

The LLM should estimate relevance. A deterministic benchmark policy should then map relevance to reading action, for example:

```text
3 HIGHLY_RELEVANT -> READ_FULL
2 RELEVANT        -> READ_SECTIONS
1 TANGENTIAL      -> REFERENCE_ONLY
0 NOT_RELEVANT    -> DISCARD
```

This makes the screening protocol easier to reproduce and prevents a second unconstrained LLM decision from eliminating the efficiency benefit of the relevance classifier.

A second threshold-based policy should also be evaluated directly:

```text
Predicted relevance >= 2 -> active reading
Predicted relevance < 2  -> no active reading
```

Quality and efficiency must remain separate axes. A model that preserves all relevant literature but reduces no reading is safe but operationally weak; a model that reduces reading aggressively but misses relevant papers is efficient but scientifically unsafe.

## Ground-truth limitation

The current ground truth is human-supervised and AI-assisted rather than independent human-only labeling. It is suitable for engineering iteration and controlled baseline comparison, but publication-quality claims should either:

- obtain an independent human-only review, or
- explicitly report the labeling provenance and quantify inter-rater agreement in a later version.

The current dataset also contains no class-0 papers and is strongly enriched for relevant literature. This limits evaluation of discard precision and can depress or distort some four-class macro metrics. A later benchmark version should add clearly irrelevant documents while preserving the frozen v0.1 set for comparability.

## Immediate experimental sequence

### A001 analysis

1. Inspect `comparison.csv` and identify all disagreement patterns.
2. Produce the complete 4x4 confusion matrix.
3. Identify false positives at the binary threshold GT >= 2.
4. Separate one-step ordinal errors from larger relevance disagreements.
5. Record whether the model systematically overestimates relevance.

### A002 — deterministic reading policy

Keep the A001 model, prompt, corpus, temperature, seed, and context unchanged.

Change only the reading-policy derivation so it is deterministic from predicted relevance. Recompute human-reading reduction and relevant-paper retention without changing the relevance predictions themselves.

This isolates policy design from model quality.

### A003 — prompt calibration

Only after A002, test a versioned prompt designed to improve discrimination between:

- TANGENTIAL vs RELEVANT;
- RELEVANT vs HIGHLY_RELEVANT.

Do not optimize against a single observed error. Changes should be defined before rerunning the full benchmark.

Primary acceptance criteria should preserve relevant-paper recall while reducing false positives and improving ordinal agreement.

### Dataset v0.2

Extend the evaluation set with clearly irrelevant papers and, if possible, a more balanced class distribution.

Do not replace v0.1. Keep both versions so all future models can be compared against the original frozen baseline.

### Resource telemetry

Before comparative model experiments, add automatic collection of:

- VRAM and RAM;
- GPU utilization;
- GPU power at fixed sampling intervals;
- integrated energy in Wh;
- wall-clock time;
- tokens and throughput.

Energy must be integrated over time; peak power must not be reported as energy consumption.

### Retrieval experiments

Do not move directly to full RAG.

Use a controlled progression:

```text
A001  LLM-only
A002  deterministic reading policy
A003  calibrated LLM-only prompt
B001  dense retrieval + LLM
C001  hybrid dense+sparse retrieval + LLM
D001  hybrid retrieval + reranker + LLM
E001  citation-aware full RAG
```

Retrieval quality should be evaluated separately from final answer/screening quality using Hit Rate@K, Precision@K, Recall@K, MRR, and nDCG.

## Decision gate before RAG

The next development stage should not be selected only because RAG is architecturally planned. First determine whether the current limitation is primarily:

- poor reading-policy design;
- poor relevance calibration;
- insufficient title/abstract evidence;
- or missing full-text retrieval.

A002 and A003 are intended to separate these causes before retrieval is introduced.

## Current conclusion

A001 demonstrates that Qwen3-30B-A3B-Instruct-2507 Q3_K_M can perform reliable high-recall local literature screening on the RX 9060 XT 16 GB while producing fully structured outputs. However, the system is currently too conservative to reduce human reading and has limited four-class ordinal agreement. The immediate research priority is therefore calibration and policy separation, not yet full RAG deployment.
