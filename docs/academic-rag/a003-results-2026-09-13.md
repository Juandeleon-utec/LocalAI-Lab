## Interpretation

A003 improves ordinal calibration substantially. Exact class accuracy, macro F1, MAE, and quadratic weighted kappa all improve while binary relevant-paper recall remains perfect.

However, the binary screening behavior does not improve: relevant-paper precision remains 0.864 and active-reading reduction remains 0.083. The stricter prompt mainly moves papers from class 3 to class 2 rather than removing the existing class-1 false positives from the active-reading set.

This is visible in the class-3 metric: recall falls from 1.000 to 0.500. Therefore A003 is better calibrated across the 0–3 relevance scale, but it is not yet a better literature-reduction policy.

The result separates two objectives that must not be conflated:

1. **ordinal relevance calibration** improved;
2. **binary screening efficiency** did not improve.

A003 should therefore not replace A001 solely on the basis of reading-effort reduction. It is useful as a calibrated prompt candidate for later validation, but its class-3 behavior and unchanged false-positive set require further study.

## Scientific caution

A003 was designed after inspecting A001 errors on the same 24-paper corpus. It is therefore a development-set calibration result, not an independent validation. Academic Screening v0.1 remains frozen.

The current corpus also contains no ground-truth class-0 papers and is strongly enriched for relevant studies. Specificity and discard performance cannot be characterized adequately from v0.1.

Macro F1 must also be interpreted cautiously because class 0 has zero ground-truth support in v0.1.

## Decision

Do not continue tuning the prompt against Academic Screening v0.1. Additional prompt tuning on the same 24 papers would increase overfitting risk.

The next priority is to build an independent or expanded Academic Screening v0.2 evaluation set containing clearly irrelevant and borderline papers. Prompt v0.2 should then be tested without further calibration on that hold-out material.

In parallel, begin the retrieval track as a separate experiment rather than as another prompt-tuning step. The first retrieval experiment should be a controlled dense-retrieval baseline with explicit retrieval metrics before evaluating end-to-end RAG quality.
