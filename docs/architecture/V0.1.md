# Architecture V0.1

## High-level architecture

```text
                  Remote workstation
                         |
                  SSH / VPN / HTTPS
                         |
                 +------------------+
                 |   LocalAI-Lab    |
                 |     Server       |
                 +------------------+
                         |
                 OpenAI-compatible API
                         |
             +-----------+-----------+
             |                       |
        Coding mode             Research mode
             |                       |
      Qwen3-Coder family        Academic LLM
             |                       |
        Coding agent                 RAG
                                     |
                         Embeddings + Reranker
                                     |
                               Vector DB
```

## Hardware baseline

```text
Intel Core i5-14600KF
64 GB system RAM
AMD Radeon RX 9060 XT 16 GB
NVMe storage
```

## Operating principle

Only one main LLM is expected to remain loaded at any given time. Supporting RAG components may remain active depending on measured memory consumption.

## Initial service concept

```text
localai-code.service
localai-research.service
localai-rag.service
localai-vector-db.service
localai-webui.service
```

The exact service layout will be refined after the first working deployment and benchmarked before being considered stable.

## Observability requirement

Production services should expose structured logs and enough telemetry to associate a benchmark run with its model configuration, resource consumption and result.
