# Phase 4 Final Baseline — ROCm 10 / RX 9060 XT

Date: 2026-09-01

## Summary

Phase 4 validates AMD GPU compute on the LocalAI-Lab server using the Radeon RX 9060 XT and ROCm 10.0. The GPU is correctly bound to `amdgpu`, exposed through `/dev/kfd`, detected by ROCm as `gfx1200`, and successfully executes a compiled HIP kernel.

## Platform

- Hostname: `ia-server`
- Operating system: Ubuntu Server 24.04.4 LTS
- Kernel: `7.0.0-30-generic`
- CPU: Intel Core i5-14600KF
- RAM: approximately 64 GB
- GPU: AMD Radeon RX 9060 XT 16 GB
- PCI device ID: `1002:7590`
- PCI address: `03:00.0`
- Kernel driver: `amdgpu`


The APT runtime installation did not include the HIP development headers required for compiling test applications. In particular, `hip/hip_runtime.h` was absent from `/opt/rocm`.

## Development environment

A dedicated Python virtual environment was created for the ROCm 10 development toolchain:

```text
~/rocm10-devel
```

The development package was installed using the ROCm Python package with development and `gfx1200` components.

The resulting HIP compiler is:

```text
/home/jpdeleon/rocm10-devel/bin/hipcc
```

The HIP header was found at:

```text
/home/jpdeleon/rocm10-devel/lib/python3.12/site-packages/_rocm_sdk_core/include/hip/hip_runtime.h
```

## Runtime library path

The executable initially failed at runtime because the dynamic linker could not resolve:

```text
libamdhip64.so.7
```

For the Python-installed ROCm SDK, the required runtime library directories were exported explicitly:

```bash
SP="$HOME/rocm10-devel/lib/python3.12/site-packages"
export LD_LIBRARY_PATH="$SP/_rocm_sdk_core/lib:$SP/_rocm_sdk_libraries/lib:${LD_LIBRARY_PATH:-}"
```

## HIP compute validation

The test program was compiled explicitly for the RX 9060 XT architecture:

```bash
hipcc --offload-arch=gfx1200 ~/hip_test.cpp -o ~/hip_test
```

Compilation completed successfully for `gfx1200`. The compiler emitted warnings because the sample program does not inspect the return values of several HIP API calls; these warnings did not prevent compilation.

The compiled program was then executed:

```bash
~/hip_test
```

Observed result:

```text
GPU: AMD Radeon RX 9060 XT
Result: PASS
```

## Interpretation

This result validates the complete GPU compute path:

```text
Ubuntu 24.04.4
    -> Linux 7.0.0-30
    -> amdgpu
    -> RX 9060 XT 16 GB
    -> ROCm 10.0
    -> HIP
    -> gfx1200 compiled kernel
    -> successful GPU execution
```

Phase 4 is therefore considered complete.

## Reproducibility note

The current validated combination should be preserved for subsequent benchmarks unless a deliberate platform change is being tested. Kernel, ROCm version, HIP toolchain, target architecture, environment paths and relevant environment variables should be recorded with every benchmark run.
