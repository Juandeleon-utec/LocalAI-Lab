## Observations requiring action

1. Change system time zone from `Etc/UTC` to `America/Montevideo` for administrative consistency.
2. Confirm whether the hostname `ia-server` will remain the permanent LocalAI-Lab hostname.
3. Review the Ubuntu LVM layout: the root filesystem currently uses only 100 GiB from a roughly 950.8 GiB LVM partition. Determine whether free extents should be allocated to `/`, a dedicated model volume, or another logical volume.
4. Identify the purpose and current contents of `/dev/sdb1` before modifying it.
5. Preserve or explicitly decommission the old Proxmox layout on `/dev/nvme0n1` only after confirming whether any data is still needed.
6. Physically install and validate the AMD Radeon RX 9060 XT before starting ROCm validation.
