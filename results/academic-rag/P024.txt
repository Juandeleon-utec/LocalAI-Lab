1. Introduction 
Electric motors are critical equipment in power systems. Once a fault or shutdown occurs, it will not only damage 
the motor itself but also lead to huge economic losses and even potential casualties. Therefore, the early prediction 
and diagnosis of potential motor faults are of great significance [1-2]. At present, motor fault diagnosis approaches 
could be classified into two categories: traditional diagnosis approaches and the methods with utilizing deep learning 
algorithms. Traditional fault diagnosis methods rely on manual extraction of effective signal features from recorded 
motor operation data, and then use shallow machine learning algorithms such as support vector machines, random

Abstract 
Vibration signals are often used to analyze and recognize the characters of faults that verify in the operation of induction motors. 
At present, the processing method of fault data is mainly through expert judgment and analysis, and the processing cost is high. 
In recent years, induction motor fault data processing models with deep learning method have been utilized in induction motor 
fault diagnosis tasks. In the study, a type of deep learning algorithm of graph convolutional neural network based on multi-head 
attention enhancement is proposed to determine the fault type of induction motor by using time series fault data. The proposed 
method firstly obtains the extended time sequence feature representation, encodes the input fault node data through utilizing 
graph convolutional network, and finally realizes the obtained fault type classification of induction motor through recurrent 
neural network and nonlinear layer. The corresponding experimental results shown that the proposed approach could achieve the 
competitive performance in certain dataset.

2. Model Design for Motor Fault Diagnosis Analysis 
Motor fault signals are usually single time-series vibration signals, and the cost of manual data processing and 
analysis is high. To tackle the problems above, we propose an approach based on graph convolutional network 
enhanced by the multi-head attention mechanism (GCN-MHAM) to mine and obtain the original fault vibration 
signals of motors. As illustrated in Fig. 1, the overall framework comprises four main modules: 
(1) Multi-head attention layer: this multi-head attention framework [9] can be utilized to map the original 
differential fault signals into different vector spaces. After vector concatenation, the original fault feature signals are 
extended to higher feature dimensions. Also, the algorithm uses conductivity and modularity to discover the nodes in 
the same cluster; the algorithm selects two nodes with maximum edge weight as an initial cluster; then it selects a 
node from neighborhood nodes with maximum edge weight.

(2) Graph convolutional neural network layer: this graph convolutional layer calculates the corresponding 
subspace cosine similarity between the extended node vector value at different time instants to obtain similarity 
scores. The Top-K feature vector pairs are selected as node pairs with potential edge connections in the graph, so as 
to construct an adjacency matrix composed of 0/1 weights. Through the aggregation operation between nodes, 
feature encoding among nodes at different distances, especially long-range nodes in the time series, is realized. To 
be more specific, the network structure node relevance between two different layers are primarily affected by two 
analysis elements, namely, structure similarity (relation-based) and interaction layer structure (shape-based). Assume 
that the network node relevance between two different interaction layers is excellent whether the corresponding 
nodes could achieve more topology value of the node structure. 
(3) Sequential learning module: The LSTM network is introduced to further learn temporal features in the 
sequence, and finally a comprehensive temporal representation within a certain range is obtained. 
(4) Classifier network: An effective prediction of fault types is achieved by using a classification activation 
function based on Softmax.

4. Conclusion 
 In this study, a fault motor classification model based on multi-head attention-enhanced graph convolutional 
neural network is proposed. After differential processing on the data, the adopted multi-head attention mechanism 
can obtain high-dimensional signal feature representations from low-dimensional features through multi-head 
mapping. The graph convolutional network is then used to perform graph construction and node aggregation 
operations to achieve better temporal feature encoding, thereby improving the performance of motor fault 
classification. In the future, based on the above ideas, this paper will focus on the over-smoothing problem in graph 
convolutional networks, so as to improve the prediction performance of the model when a large number of graph 
convolutional layers are employed. Moreover, we would like to verify the topology structure of the network 
structure layer and specific number. For instance, the effect of proposed model framework might lead to the 
interaction of the corresponding entity layers. Actually, the dynamic and variation can be evaluated certain other 
evaluation metrics such as TTSC and TOSST. Of course, we note that a series factor selection methods are mainly 
based on the network topology structure.
